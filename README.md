# 幸福模擬器

幸福小組七週互動遊戲。投影片還在，只是活了過來 —— 你照樣一頁一頁講，講到轉折處畫面跳成互動頁，全場拿手機參與，玩完再回到你的信息。

Web100 系列第 6 個專案。七週一週開一關，每開一關發一個 Release。

**這是主持人的工具，不是自助遊戲。** 沒有人先準備好信息、沒有人在對的時機接話，它只是一堆會跑的動畫。

## 網址

```
系列頁      /happiness/zh-TW/
第一關      /happiness/w1/zh-TW/          ← 主持人大螢幕
玩家手機    /happiness/w1/zh-TW/p/?room=XXXX
```

主畫面一打開就會跟 Worker 要一個四碼房號，同時把 QR 畫出來。房號放在查詢字串 `?room=XXXX`，掃 QR 進來就是這個網址；掃不到就到玩家網址手動輸入四碼。房號在網址上，所以主持人重整頁面不會換房。

## 開發

```bash
npm install
npx wrangler dev --ip 0.0.0.0     # 本機 + 區網都連得到
npx wrangler deploy
```

`wrangler dev` 就是完整的伺服器（Worker + Durable Object 都在本機跑），**現場斷網時可以直接用它跑完整場**，玩家連同一個 Wi-Fi、開你電腦的區網網址就好。

同一台電腦要開多個玩家測試，網址加 `&seat=2`、`&seat=3` —— 不加的話同一個瀏覽器的分頁會共用同一個身分。

## 結構

```
worker/
  index.js       路由：/api/new-room、/ws，其餘丟給靜態資源
  room.js        Durable Object：一個房號一個房間
  game.js        第一關的規則（純函式）
  w1-data.js     拍賣標的、三組機會與命運卡、經文
public/happiness/
  zh-TW/         系列頁（主持人的準備台）
  shared/        七關共用：像素風元件、房間連線、週卡、QR
  w1/            第一關的主畫面與手機頁
```

七關共用同一個 Durable Object class，`/ws?week=N&room=XXXX` 決定連到哪一間。加第二關就是加 `worker/w2-data.js`、`worker/w2-game.js`、`public/happiness/w2/`，共用層不用動。

## 隱私

三條線，跟設計文件一致：

- **重擔那句話不會離開玩家的手機。** 它存在他自己的 localStorage，伺服器只收到「有沒有寫」這個布林值。只有本人勾了「我願意分享」，那一句才會送上來、才會出現在大螢幕上。
- **房間狀態不做長期保存。** 寫進 DO storage 只是為了連線休眠後醒來還接得上；最後一個人離線六小時後整個刪掉。不做帳號、不做跨週資料庫。
- **週卡在瀏覽器端用 canvas 生成，圖不上傳。**

跨週的連續性靠玩家相簿裡那張週卡：下一關開場請他打開卡片、輸入上面的數字。忘記帶、上週沒來、第一次來，就直接評估現在的自己 —— 兩種都合法，不用解釋。

## 第一關的規則

- **拍賣**：每人 100 點，每樣 20 秒同時暗標，最高者得、同價時先出價者得、出價不得超過剩餘點數
- **不買就是財富**：沒花掉的點數就是你的財富，也決定你會抽到哪一組卡
- **標的數依人數**：6–8 人拍 6 樣、9–12 人拍 8 樣、13 人以上全開 10 樣。最後一樣永遠是「？」，第一關不揭曉（第二關開標時是「永生」）
- **機會與命運**：依剩餘點數分甲（≤20）／乙（≥60）／丙（21–59）三組發卡，組內不重複。該組有人就一定有人抽到重擊卡；某組當天沒人，大螢幕會把那張卡標成旁白讓主持人念
- **問號卡**：跨組隨機 1–2 張，不加不扣，第一關完全不解釋（第五關才會調出來）
- **兩條指數**：上面是**幸福指數**（會被事件打上打下），下面標籤只有 `???`（領受經文 +10、收尾禱告 +5，只會漲，上限 95）。第一關不解釋 `???` 是什麼，有人問就說「下週」——第二關才正名為**幸福根基**
- **沒有排行榜**：底下是全場共用的能量條。低分不用紅色、不寫「危險」

## 主持人怎麼控

| 動作 | 怎麼做 |
|---|---|
| 翻頁 | 底下按鈕，或鍵盤 `→` `空白鍵` / `←` |
| 跳頁 | 底下的下拉選單（跳到「幸福拍賣會」會重跑拍賣） |
| 手動加減分 | 左側每位玩家的 `＋` `−`，一次 5 分 |
| 拍賣控制 | 立即開標／+15 秒／每項之間等我／重跑拍賣 |
| 重發事件卡 | 事件卡那兩頁才會出現，重抽並還原分數 |

每一頁的主持提示直接印在大螢幕上，照著念就好。

卡組文案是台灣三四十歲上班族的版本，請照你們 BEST 的實際處境調整。

## 現場注意

- **散會前一定要每個人都存到卡**。直接問「存好的舉手」。不要說回家再存。
- **手機先關掉自動鎖屏。**
- **斷網備案還是要準備**：拍賣改紙本標單、機會與命運印成實體卡抽、分數寫白板，整關照樣跑得完。
- **第一週亂填 100 分很正常**，那是防衛，不要糾正。機會與命運那關他自己會發現那 100 分怎麼縮水的。
