# 幸福模擬器

幸福小組七關互動遊戲。投影片還在，只是活了過來 —— 你照樣一頁一頁講，講到轉折處畫面跳成互動頁，全場拿手機參與，玩完再回到你的信息。

Web100 系列第 6 個專案。七關，一關一個 Release。**幾天開一關由主持人決定，系統不假設每週一次。**

**這是主持人的工具，不是自助遊戲。** 沒有人先準備好信息、沒有人在對的時機接話，它只是一堆會跑的動畫。

## 網址

```
系列頁      /happiness/zh-TW/
第一關      /happiness/w1/zh-TW/          ← 主持人大螢幕
第二關      /happiness/w2/zh-TW/
第三關      /happiness/w3/zh-TW/
玩家入場    /1 /2 … /7                    ← 大螢幕上印的就是這個，最短、最好打
主持人備忘錄 /h1 /h2 … /h7                ← 右上角按鈕跳出的 QR 編的就是這個
（兩個都吃 ?room=XXXX，帶了就直接進那一間，沒帶就出現輸入四碼的畫面）
玩家手機    /happiness/wN/zh-TW/p/?room=XXXX
```

系列頁（`/happiness/zh-TW/`）上有「我要加入房間」，點開是一個 popup：輸入四碼房號、選第幾關，就導到那一關的玩家頁。組員自己打網址進來的時候，那是他唯一找得到的入口。

主畫面一打開就會跟 Worker 要一個四碼房號，同時把 QR 畫出來。房號放在查詢字串 `?room=XXXX`，掃 QR 進來就是這個網址；掃不到就到玩家網址手動輸入四碼。房號在網址上，所以主持人重整頁面不會換房。

## 開發

```bash
npm install
npx wrangler dev --ip 0.0.0.0     # 本機 + 區網都連得到
npx wrangler deploy
```

`wrangler dev` 就是完整的伺服器（Worker + Durable Object 都在本機跑），**現場斷網時可以直接用它跑完整場**，玩家連同一個 Wi-Fi、開你電腦的區網網址就好。

同一台電腦要開多個玩家測試，網址加 `&seat=2`、`&seat=3` —— 不加的話同一個瀏覽器的分頁會共用同一個身分。

## 結構

```
worker/
  index.js       路由：/api/new-room、/ws、/1–/7、/h1–/h7，其餘丟給靜態資源
  room.js        Durable Object：一個房號一個房間
  w1-game.js     第一關的規則（純函式）
  w2-game.js     第二關的規則
  w1-data.js     拍賣標的、三組模擬事件卡、經文
  w2-data.js     幸福人生商店的貨架與折舊率、買三送一的那一份、經文、教導頁
public/happiness/
  zh-TW/         系列頁（主持人的準備台）
  shared/        七關共用：像素風元件、房間連線、週卡、QR、備忘錄渲染器、人生資產圖示
  w1/            第一關：主畫面、玩家手機頁、主持人備忘錄（notes.js）
  w2/            第二關：同上
```

七關共用同一個 Durable Object class，`/ws?week=N&room=XXXX` 決定連到哪一間。`room.js` 裡的 `GAMES = { 1: W1, 2: W2 }` 決定套哪一關的規則 —— **加第三關就是加 `worker/w3-*.js`、`public/happiness/w3/`，再到 `GAMES` 多一行。**

## 隱私

三條線，跟設計文件一致：

- **重擔那句話不會離開玩家的手機。** 它存在他自己的 localStorage，伺服器只收到「有沒有寫」這個布林值。只有本人勾了「我願意分享」，那一句才會送上來、才會出現在大螢幕上。
- **房間狀態不做長期保存。** 寫進 DO storage 只是為了連線休眠後醒來還接得上；最後一個人離線六小時後整個刪掉。不做帳號、不做跨週資料庫。
- **週卡在瀏覽器端用 canvas 生成，圖不上傳。**

跨關的連續性只靠一件事：玩家相簿裡那張週卡上的**幸福指數**，下一關開場請他自己輸入。忘記帶、上一次沒來、第一次來，就直接評估現在的自己 —— 兩種都合法，不用解釋。**每一關的遊戲本身都是獨立的**，不吃前一關的資料。

## 第一關的規則

- **拍賣**：每人 100 點，每樣 20 秒同時暗標，最高者得、同價時先出價者得、出價不得超過剩餘點數
- **不買就是財富**：沒花掉的點數就是你的財富，也決定你會抽到哪一組卡
- **標的數依人數**：5 人以下 8 樣、6 人以上 10 樣（全開）。第一樣是不計分的試拍品，讓大家先按過一次出價
- **拍賣加分**：翻到結算頁時自動加幸福指數 —— 每標到一樣 +5，買最多樣的人再 +5、剩最多錢的人 +10、剩最少錢的人 +5。加完可以超過 100
- **模擬生命中的事件**：依剩餘點數分三組發卡（≤20／≥60／21–59），分別對到「身負重擔」「條件令人羨慕卻空虛」「達不到目標」三種處境，組內不重複。**大螢幕上不分型**，結算頁把每個人抽到的卡都列出來
- **兩條指數**：上面是**幸福指數**（會被事件打上打下），下面標籤只有 `???`（領受經文 +10、收尾禱告 +5，只會漲，上限 95）。第一關不解釋 `???` 是什麼，有人問就說「下一關」——第二關才正名為**幸福根基**
- **沒有排行榜**：底下是全場共用的能量條。低分不用紅色、不寫「危險」

## 第二關的規則

**這一關不吃第一關的任何資料。** 上一次沒來、忘記帶卡片、第一次來的人，走的都是同一條路 —— 今晚每個人當場挑，然後一起坐時光機。拍賣的結果留在他自己的卡片和主持人的記憶裡，那是接話的材料，不是系統的輸入。

- **接關**：卡片上那兩個數字都自己打（幸福指數、幸福根基）。忘記帶卡片的人才改填「這是你第幾次來」，系統用 `15 ×（次數−1）` 估一個。第一次來的人幸福指數自由填、根基填 0
- **幸福人生商店**：貨架上十一樣人生資產，不用考慮時間和錢，每個人挑 **3 樣**。而且**買三送一** —— 挑滿三樣，第十二格那個金色的「？」就進他的袋子，但**要到最後才知道是什麼**
- **公布前三名**：全場最多人挑的三樣，底下列出每個人的袋子（三樣＋一個問號）。**這裡不碰那個問號**
- **世界越來越進步，但人卻越來越痛苦**：全場投票同不同意，主持人接著比例分享
- **人生時光機**：年份三秒跑完三十年，大螢幕和每支手機同步
- **三十年後的同一家店**：十二格全部攤在同一頁，每一格是一張蓋著的牌。**正面是剛剛誰挑了它，翻過去才是折舊率和為什麼** —— 主持人點卡片（或按空白鍵、或用手機上的備忘錄）一張一張翻，**翻開的那一秒挑了它的人才掉分**。每一樣掉 `clamp(折舊率 × 5, 1, 5)` 分，只算他挑的那三樣。挑工作和名聲的掉最慘（−15），挑關係的掉最少（−6）。**沒有一種挑法是不掉分的**。翻完之後有一頁結算，攤開每個人掉了多少
- **拆開那一份**：寶箱打開，它叫**生命**，折舊率 0%。**「你一開始就拿到了，只是不知道它是什麼。」** 翻到這一頁**全場幸福指數 +20**（給每一個人，不是給按按鈕的人），拉回來的比整晚掉下去的還多。恩典不是後來開放給你，是本來就已經是你的 —— 買三送一就是為了玩出這件事
- **盜賊和「我」分別是什麼**：盜賊是讓人與神隔絕的東西；人追這些本來想遠離痛苦，卻越追越痛苦。生不由己、人生的癮。神給的是抵擋罪的能力和對生命的盼望
- **正名**：那條 `???` 變成**幸福根基**。這不是解鎖，是替一條從第一關就在跑的線正名
- **大螢幕十八頁，每一頁都在一個畫面裡看完**，不用捲動

## 主持人怎麼控

| 動作 | 怎麼做 |
|---|---|
| 翻頁 | 底下按鈕、鍵盤 `→` `空白鍵` / `←`，或你手機上的備忘錄 |
| **主持人備忘錄** | 右上角的「📱 主持人備忘錄」按鈕（或按 `N`），跳出 QR 用手機掃。掃不到就打 `/h1`、`/h2` |
| 備忘錄同步 | **兩個方向都會同步** —— 大螢幕翻到哪它跟到哪，從它翻頁大螢幕也跟著走 |
| 跳頁 | 底下的下拉選單（第一關跳到「幸福拍賣會」會重跑拍賣） |
| 拍賣控制（W1） | 立即開標／+15 秒／每項之間等我／重跑拍賣 |
| 重發事件卡（W1） | 事件卡那兩頁才會出現，重抽並還原分數 |

### 大螢幕上只放給房間看的東西

主持提示**不印在大螢幕上**，它們在你手機的備忘錄裡：要念的話（金）、要做的動作（綠）、不要做的事（橘），加上那一頁最該盯的即時數字。備忘錄跟大螢幕連同一個房間，會自己跟著翻頁，也可以反過來從手機翻頁——所以你可以離開電腦走動。

判斷一句話該放哪裡：**它如果被一個組員唸出來會不會很奇怪？** 會的話就是備忘錄的內容。

> 那個網址能翻頁。房號本來就是公開的，所以真正的風險是「有人亂翻頁」——惡作劇等級，不是安全問題。所以不加鎖，但也別讓它整晚掛在牆上（翻頁之後入場頁就消失了）。

## 現場注意

- **散會前一定要每個人都存到卡**。直接問「存好的舉手」。不要說回家再存。
- **手機先關掉自動鎖屏。**
- **斷網備案還是要準備**：拍賣改紙本標單、模擬事件印成實體卡抽、分數寫白板，整關照樣跑得完。
- **第一週亂填 100 分很正常**，那是防衛，不要糾正。模擬事件那一關他自己會發現那 100 分怎麼縮水的。

## 第一關留下什麼

散會前請同工把這三件事打進系列頁的「現場筆記」（只存在那台裝置）：

1. **拍賣配置** —— 第二關開場可以問一句「你們上一次買了什麼」
2. **誰抽到重擊卡** —— 「上一次金融風暴那位，還好嗎」

這三件事是**主持人接話的材料，不是系統的輸入** —— 第二關不讀它們，上一次沒來的人今天照樣玩得到全部。
