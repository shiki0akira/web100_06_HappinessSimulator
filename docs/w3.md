# 第三關 · 萬世巨星

> 幸福模擬器 · 執行腳本 · 敘事功能：**遇見關鍵角色**
> 先讀 [architecture.md](architecture.md)。這一份只寫這一關特有的東西。

打開**人生模擬器**：二十到六十歲五個岔路、三十二個結局，每個人自己選一條走完一生。
每一個岔路當場公布 —— **一邊加分、一邊扣分，而且沒有一條規則貫穿五題。**
三十二種人生一次攤開的時候只剩一句話：沒有人算得到下一步。

那為什麼我們做不出最好的選擇？**因為罪** ——
而且第一句話就要把它跟法律切開：講的是心裡那些**連自己都管不住的念頭**，不是犯了什麼法。
七宗罪貼成標籤，每一個配一句人話。

然後介紹今天的主題：一位**萬世巨星**。八句話猜猜看是誰說的，笑完才發現有四句是他說的。
最後一句是今天的經文：**我就是道路、真理、生命。**

| | |
|---|---|
| 時長 | 約 35 分鐘（**七關裡唯一超過 25 分的一關**） |
| 經文 | **約翰福音 14:6** |
| 互動點 | 4 個：走地圖、猜句子、天堂地獄投票、祝福禱告 |
| 頁數 | 17 頁，**每一頁都在一個畫面裡看完，不用捲動** |
| 機制大事件 | 沒有 |
| 語氣 | 接在被打到低點的第二關之後，整關往上。**不決志、不施壓。** |

## 〇、這一關的分數只在一個地方動

**幸福指數整晚只有第 3–4 頁（人生模擬器）會變。** 其他地方一分都不動 ——
猜句子不加分、罪那一段不加不扣、天堂地獄投票不加分、到父那裡去也不加分。

| 什麼時候 | 誰 | 動什麼 |
|---|---|---|
| **每公布一個岔路（第 3 頁 × 5 次）** | 每個人照自己選的那一邊 | **幸福指數 一邊加、一邊扣** |
| 領受經文（第 13 頁） | 領受的人 | 幸福根基 **+10** |
| 祝福禱告（第 15 頁） | 送出的人 | 幸福根基 **+5** |

> ### ⚠️ 這一關會有人掉分
>
> 五個岔路一正一負，全程最多掉 19 分、最多加 35 分。**這是刻意的** ——
> 每一條都加分就算不出「你算不到」，只算得出「你加多少」。
>
> **掉分的人不要安慰他，加分的人不要恭喜他。** 一恭喜，這一頁就從論證變成比賽。
> 而且不管怎麼掉，領受經文和禱告的幸福根基一分不少 —— 那條線只會漲。

**這一關的幸福根基就是七關固定的那 +15。** 沒有額外的加分 ——
「他替你付了」那一頁**一分都不加**，那一段的重量靠你講，不靠數字。

> **為什麼猜句子不給分。** 給了就變成搶答比賽，而那一頁的功能是好玩和認出他，不是比誰記得多。
> 而且分數一旦散在四五個地方，「只有第一個遊戲會動」這件事就不成立了 ——
> **而那正是這一關要講的：你的選擇會影響結果，但你算不到結果。**

## 一、主遊戲：人生模擬器（第 3–4 頁）

大螢幕上**左右兩大格**：左邊 A、右邊 B。手機上兩顆單選按鈕，點來點去都可以。
**誰選了哪一邊，選完馬上出現在大螢幕的格子裡** —— 那一行就是「大家選完了沒」。

全場選完，主持人按**「公布結果」**：兩邊的結果和加減**同時**翻出來，分數在這一刻才動。
再按一次就是「往前走」，進下一個岔路。**一顆按鈕按到底，不會漏按。**

大螢幕上那一句題目**要把人放進那個年紀的場景裡**，光寫「20 歲」太乾，
讀起來像表格的欄位名，不像在問他：

| 題目 | A | B |
|---|---|---|
| **當你 20 歲高中畢業時…** | 先去打工存錢 **−4** | 借錢去讀想讀的科系 **+6** |
| **當你 30 歲在公司站穩腳步時…** | 接下那個要常常加班的位子 **+8** | 推掉它，準時下班 **−3** |
| **當你 40 歲存到第一筆錢時…** | 把存下來的錢拿去投資 **−6** | 全部拿去付房子的頭期款 **+5** |
| **當你 50 歲孩子都大了時…** | 留在原本的公司做到退休 **−2** | 換一個跑道，重新開始 **+9** |
| **當你 60 歲快退休時…** | 搬回老家，陪爸媽最後那幾年 **+7** | 留在城市，每個月回去一次 **−4** |

> **標題旁邊不掛「二十歲開始，五個選擇…」，題目旁邊也不掛「1 / 5」。**
> 底下那一句已經把人放進場景了，上面再講一次規則只會把這一頁變成說明書。
> 進度看控制列那顆按鈕就好（「公布結果（1/5）」）。

公布的時候，每一邊會翻出一句「後來怎麼了」：

| | |
|---|---|
| 20 歲 · 打工 | 你比同學早三年有存款。那三年的事你一件也沒參與到。 |
| 20 歲 · 讀書 | 你欠了一筆學貸。但那四年你是真的在讀你喜歡的東西。 |
| 30 歲 · 接下 | 那幾年你很累。可是你到現在還會想起那個把你帶起來的主管。 |
| 30 歲 · 準時 | 你準時下班了十年。第十一年公司說這個位子不需要你了。 |
| 40 歲 · 投資 | 你買在最高點。那筆錢到現在還沒有回來。 |
| 40 歲 · 買房 | 房子不大。但那是二十年後你唯一沒有煩惱過的事。 |
| 50 歲 · 留下 | 你做到退休。最後那五年你每天都在看時鐘。 |
| 50 歲 · 重來 | 四十九歲重來一次很蠢。五十五歲那年你才知道不蠢。 |
| 60 歲 · 回家 | 你陪了他們最後四年。那四年的事，你一件都不後悔。 |
| 60 歲 · 每月 | 每個月回去一次。你以為還有很多次。 |

> ### ⚠️ 正負不准有規律
>
> 二十歲是「花錢去讀書」贏、三十歲是「拚」贏、四十歲是「買房」贏、
> 五十歲是「換跑道」贏、六十歲是「回老家」贏。**沒有一條規則貫穿五題。**
>
> 「選家人就對了」「選穩的就對了」「選拚的就對了」—— 三句都不成立，這是設計，不是隨機。
> **而且不准由你在中途講出任何一條規律**：規律一被講出來，第 4 頁那句話就沒用了。

> **不要事先講「這裡面有陷阱」。** 讓他們用自己以為對的方式選完，落差才有感。

> **公布之後那一個岔路就鎖住了**，改不了。按「公布結果」之前先確認最慢的那個人選了沒。

### 三十二個結局（第 4 頁）

五個選擇 = 2⁵ = **三十二條路**，第 4 頁**一次全部攤開**（兩欄十六列）。
**有人走到的排最上面，走的人越多越上面**，掛著名字；沒有人走到的那些淡淡地排在後面。

每一條的總分就是那五個選擇的加減總和 —— 從 **−19** 到 **+35**。

| 有人走到的例子 | 總分 |
|---|---|
| 打工 → 接下 → 買房 → 重來 → 回家 | **+25** |
| 讀書 → 接下 → 投資 → 重來 → 每月 | **+13** |
| 讀書 → 接下 → 買房 → 重來 → 回家 | **+35**（最高） |
| 打工 → 準時 → 投資 → 留下 → 每月 | **−19**（最低） |

**有人走到的那幾條大一格，而且把那五步印出來**（打工 › 接下 › 投資 › 重來 › 每月）——
「+13 你換跑道那年…」看不出他是怎麼走到那裡的，印出那五步他才接得回自己剛剛按的那五下。

> **結局頁要把三十二條全部攤開**，不是只顯示自己走到哪。
> 只看自己那一條是「我運氣好／不好」；三十二條一起看才是「原來沒有規則」。

> **不要念完三十二句。** 挑有人走到的那幾條念，其他的讓他們自己看。

### 第 4 頁主持人要講的（畫面上沒有）

> 「大家都知道選擇很重要。人生中每一個選擇，都會影響到後面的結果。」
> 「三十二條路都在這裡。你剛剛走的是其中一條 —— 而你在選的時候，一條都看不到。」

> **先問再講：** 「有沒有人覺得自己每一步都選得很穩，結果分數是負的？」
> 通常會有人舉手 —— 那句話由他講出來比你講有力十倍。

> **這一段不要講成「所以不要努力」。** 重點是「你算不到」，不是「你不用算」。

## 二、為什麼我們做不出最好的選擇（第 5–6 頁）

**這一段是信息，不是遊戲。而且問句和答案分成兩頁。**

### 第 5 頁：問句 ＋ 一句註腳

整頁只有兩行。上面那一句是這一頁的主角，底下那一句是註腳，字級差一倍以上：

> # 為什麼我們做不出最好的選擇？
>
> 沒有人知道結果會怎麼樣。就算是 AI，也只是拿過去的大數據推測下一步 —— 推得很接近，但不是 100% 準確。

底下那一句就是上一頁那個「你算不到」的收口，照著念就好。
**念完停三秒再翻頁** —— 這一頁的戲就是那三秒的安靜，而且答案在下一頁。

> **這一頁不要自己講出答案。** 你一講，下一頁就白做了。

### 第 6 頁：因為罪

> # 因為罪
>
> 不是法律上的犯罪。是心裡的自己無法選擇的念頭與想法，影響了我們的決定。

> ### ⚠️ 第一句話一定要先把「罪」和法律切開
>
> 台灣的小組現場，「罪」第一個聯想是**犯法、是壞人、是要被抓走的人**。
> 那個聯想沒有被拆掉，後面「他替我們付了那個代價」全場都會覺得跟自己無關 ——
> 因為「我又沒犯法」。
>
> 所以第一句就是：「這裡講的罪，不是法律上的罪。是心裡的那一個。」

然後七宗罪貼成標籤，一個配一句人話。**帶過去就好，不要一個一個展開講：**

| | | | |
|---|---|---|---|
| **驕傲** 我比他強 | **貪婪** 還要更多 | **嫉妒** 為什麼是他 | **憤怒** 我受不了 |
| **色慾** 想要不屬於我的 | **暴食** 停不下來 | **懶惰** 明天再說 | |

> **「這七個我全都有過。」——先講自己。** 你把自己放進去，全場才敢承認。

接著才是你講的那一段（**不印在牆上**）：

> **聖經裡「罪」這個字，本來的意思是「射不中」—— 箭射出去，沒有中靶心。**

所以罪不是一張壞事清單，是**「我知道靶在哪裡，但我射不中」**。

接第二關：

> 「上一次講的生不由己 —— 做出自己不想做的事、停不下來的事。那就是射不中。」

接第一關：

> 「第一關你在手機上寫下的那句話、那顆壓著你的石頭 —— 那也是。」

> ### ⚠️ 三個一定要避開的講法
>
> **不要讓七個標籤變成點名。** 不要問「你是哪一個」、不要請人舉手、不要看著誰念。
> 這一頁是「我們都有」，不是「你有」。
>
> **不要用來指認誰。** 不點名、不問「你有沒有」、不舉例到在場任何一個人身上。
> **你要把自己放進去。**
>
> **不要講成「你不夠努力」。** 射不中不是懶惰，是每個人都有的無力。這跟第二關那條戒律是同一條。

> **這一頁一分都不動。** 罪一旦有分數 —— 加分變成「答對得分」，扣分變成「你承認越多扣越多」——
> 那一頁就會變成審判台，而那正是這一關最要避開的東西。

## 三、萬世巨星：開場白（第 7 頁）和揭曉（第 10 頁）

**第 7 頁是開場白，不是揭曉。** 畫面上只有「萬世巨星」四個字和一道**一閃一閃的聚光燈** ——
燈已經打下去了，光裡站著一個人，**但那是一個黑色的人影，看不出他是誰**。沒有十字架。

> 「我想先跟大家介紹一位萬世巨星 —— 就是我們今天的主題。」

> ### ⚠️ 這一頁不要講出他是誰
>
> 燈已經亮了，但你還看不清楚他 —— 那就是這一頁全部的戲。
> 講完就翻頁去玩八題，這一頁停三十秒就夠了。

**第 10 頁他的臉才出現在同一道光裡，標題上也寫出名字：「就是這一位 —— 耶穌」。**
同一個構圖、同一個位置（兩張圖的人站在同一格），多的是十字架和他的臉。

**右邊不再排他說過的那四句** —— 上一頁（第 9 頁）才剛把八題的答案看完，
同樣四句再排一次只是重複。右邊換成他留在生活裡的那四樣，那是新的東西：

| | |
|---|---|
| **西元 2026 年** | 從他出生那年開始算 |
| **聖誕節** | 他的生日 |
| **馬偕、耕莘** | 因他而蓋的醫院 |
| **輔仁、東海、真理** | 因他而辦的學校 |

（年份會自己抓今年，不用每年改。）

你要講的：

> 「我想跟大家介紹這一位 —— 萬世巨星。」
> 「有一些我們耳熟能詳的話，其實是出自於他。」
> 「在我們的生活裡，也常常可以看見他的身影。」
> **「其實，你早就已經認識他了。」**

> ### ⚠️ 這一頁畫面上一句你的台詞都沒有
>
> 「其實你早就已經認識他了」是**你要講出來的**，不印在大螢幕上 ——
> 印在牆上就變成一份工作手冊，而且他們會自己讀完，你就沒有戲了。

> **四格都是陳述句，不是問句。** 2–4 公尺外的人不會替你把問號想完，
> 而且問句會讓這一頁變成又一輪搶答 —— 這一頁不是題目，是介紹。

> **不要引用你查不到出處的統計數字**（「全世界最暢銷的書」「多少億人」）。這條戒律第二關就有了。

> ### 為什麼要拆成兩頁
>
> 開場白是「我想介紹一位」，**不是「他是耶穌」**。所以第 7 頁只放一盞空的燈：
> 全場知道有一個人要出場，但還不知道是誰 —— 那個懸念撐著中間的八題。
>
> 玩完八題、公布答案之後，第 10 頁他才站進**同一道光**裡。同一個構圖、同一個位置，
> 只多了他。**那個畫面上的鏡像就是揭曉**，不用多印一個字。

## 四、主遊戲之二：這句話是誰說的（第 8–9 頁）

八題，一題一題開。**手機上三選一，點一下就好 —— 不要打字。這一頁不加分。**

**耶穌只佔四題（3、5、7、8）。** 另外四題的答案是紅過的人，而且每一題「耶穌」都在選項裡。

| # | 這句話 | 三選一 | 答案 |
|---|---|---|---|
| 1 | 做人如果沒有夢想，跟鹹魚有什麼分別？ | 耶穌／周星馳／孔子 | **周星馳**《少林足球》 |
| 2 | 人生就像一盒巧克力，你永遠不知道下一顆是什麼味道。 | 耶穌／阿甘正傳／村上春樹 | **阿甘正傳** |
| 3 | 施比受更為有福。 | 耶穌／孔子／網路上流傳的 | **耶穌**（徒 20:35） |
| 4 | 我希望你們經歷足夠多的痛苦與苦難。 | 耶穌／黃仁勳／賈伯斯 | **黃仁勳**（2024 史丹佛商學院） |
| 5 | 不要怕，只要信。 | 耶穌／灌籃高手安西教練／一句選舉口號 | **耶穌**（可 5:36） |
| 6 | 己所不欲，勿施於人。 | 耶穌／孔子／老子 | **孔子** |
| 7 | 凡勞苦擔重擔的人，可以到我這裡來，我就使你們得安息。 | 耶穌／一首台語歌／一本勵志書 | **耶穌**（太 11:28 · **第一關的卡**） |
| 8 | **我就是道路、真理、生命。** | 耶穌／老子／一句電影台詞 | **耶穌**（**約 14:6 · 今天的經文**） |

### 為什麼是這八題

- **零門檻。** 選項是他們認得的名字。**猜人名的玩法試過，不行** —— 沒有人會脫口而出曼德拉、切‧格瓦拉，而且自由打字的欄位九成的人不會打。
- **前六題只有兩題是耶穌**，所以不能無腦全選。順序是笑、笑、咦？、笑、咦？、咦 —— **一直被打亂，才會一直想。**
- **第 1 題是拿來笑的**，跟第一關開場那題「你現在有吃飽嗎」一樣：**玩法用玩的教，不用講的。**
- **第 6 題最有料。** 孔子說「己所不欲，勿施於人」，耶穌說的是反過來的那一句 ——
  「**你們願意人怎樣待你們，你們也要怎樣待人**」（太 7:12）。一個是不要做，一個是主動去做。**這一句留給你揭答案的時候講。**
- **第 7 題是第一關領的那張經文卡。** 揭答案的時候要講：「這一句，我們第一關就領過了。」——**經文卡第一次真的派上用場。**
- **第 8 題就是今天的經文。** 選項簡單到不會有人猜錯 —— 這一題不是要考他們，是要**讓那句話從他們自己手上按出去一次**。
  這時候一個字都不要解釋，它第 14 頁才會有意思。

> ### 最兇的那句不是他說的
>
> **第 4 題是這八題的靈魂。** 全場會有一半的人以為「我希望你們經歷足夠多的痛苦與苦難」是聖經 ——
> 那句話是黃仁勳講的。而耶穌那四句是：施比受更為有福、不要怕只要信、到我這裡來得安息，還有今天的經文。
>
> 揭答案的時候把這件事講出來：**「今天最兇的那一句，不是他說的。最溫柔的四句，是。」**

> ### ⚠️ 引用活人的話，出處要查得到，而且不准改寫
>
> 第 4 題是**真人講過的話**，中譯有好幾個版本。**不要為了唸起來順把它改掉** ——
> 現場一定有人會查手機。出處是 **2024 年史丹佛商學院的訪談**。
>
> 這條跟第二關「不要引用你查不到出處的統計數字」是同一條規矩：**要嘛查得到，要嘛不要用。**

> **一題一題開，開完馬上揭答案**，不要八題全部答完才對答案 —— 那會變成考試。
> 揭曉和下一題是**同一顆按鈕**：還沒揭就是「揭曉答案」，揭過了才變「下一題」。
> **不要拆成兩顆** —— 現場一定會有人只按「下一題」。

> **答錯不要有音效、不要有紅色。** 這一頁的功能是好玩，不是考倒他們。

## 五、天堂和地獄（第 11 頁）

**互動點 3 · 投票。** 這一頁取代了舊版的「死後還有審判」。

> 「你相信死後的世界有天堂和地獄嗎？」

手機上三個選項：**相信／不相信／沒有想過**。大螢幕長出比例。

> ### ⚠️ 為什麼不用「死後還有審判」
>
> 「審判」在台灣的小組現場太容易聽成恐嚇，而**用恐懼帶人是最糟的做法** ——
> 第七關要講的是「釋放與自由」，用恐懼開頭那一關就收不回來了。
>
> 改成問「你相信嗎」，把它變成一個**沒有標準答案的問題**，而不是一個宣告。
> 比例出來就是你的接話點：「有幾個人沒想過。其實我以前也沒想過。」

> **不要糾正任何一個答案，也不要追問為什麼。** 這一頁只是把門打開。
> **這一頁不加分。**

## 六、永生的生命（第 12 頁）

接第二關的下半句：

> 「上一次那一節經文說：『我來了，是要叫羊得生命，並且得的更豐盛。』」
> 「那個『我』，就是今天和大家介紹的萬世巨星 —— 耶穌。」

**為什麼我們要認識他** —— 因為前面那三十分鐘已經證明了兩件事：
**你算不到結果**，而且**你射不中**。這兩件事你自己都解決不了。

## 七、本週經文（第 13 頁）

**約翰福音 14:6（和合本）**

> 耶穌說：「我就是道路、真理、生命；若不藉著我，沒有人能到父那裡去。」

**它在同一個晚上出現三次，一次比一次重。** 這是第二關剖約 10:10 的同一個手法：

| 什麼時候 | 用哪一段 | 那時候它是什麼 |
|---|---|---|
| **第 8 頁 · 猜句子第 8 題** | 「我就是道路、真理、生命。」 | **只是一句話。** 他們按下「耶穌」，全場都對，然後就過去了。**這裡一個字都不要解釋。** |
| **第 13 頁 · 領受經文** | 整節，發卡，幸福根基 +10 | 大螢幕上只有經文，一句解釋都沒有 —— 那是你的工作。 |
| **第 14 頁 · 藉著他到父那裡去** | 「若不藉著我，沒有人能到父那裡去。」 | **這一關唯一的高風險句**，講法見第九節。 |

**「到父那裡去」把第四關接住了。** 第四關「幸福連線」的敘事功能是取得能力，所以這一關的最後一句是：

> 「他說『到父那裡去』。那條線怎麼接上——下一關。」

## 八、藉著他到父那裡去（第 14 頁）

這一頁排成 **RPG 的關卡地圖**：三個節點，中間有路連起來，每一格上面一張小插畫。

| | | |
|---|---|---|
| **① 罪使我們與父隔絕**<br>心裡的私慾 | **② 耶穌替我們付了那個代價**<br>第六週會講到 | **③ 所以我們可以到父那裡去**<br>就是天堂、永恆的生命 |
| 一條鎖鏈 | 一個十字架 | 天堂的門開著，光從裡面出來 |

一格一個東西。**不要畫成一個場景** —— 2–4 公尺外只看得出「一個東西」，場景裡的細節會全部糊掉。講的時候可以指著一格一格走過去。

> ### ⚠️ 第二格今天不展開
>
> 畫面上就寫著**「第六週會講到」**。今天只要他知道「有人已經付了」，
> 代贖那一整段留給第六關的十字架 —— 這一關已經有罪、有隔絕、有出路，再塞就滿了。

> **三格一次全部出來，不用按。** 一格一格點會讓這一頁變成一場操作，而這一頁是你在講。

> **這一頁一分都不加**（幸福指數和幸福根基都不動）。那一段的重量靠你講，不靠數字。

收尾那一句：**今天你不用做任何決定。**

## 九、「若不藉著我」怎麼講

**這是這一關最會出事的地方。** 跟第二關「不要說撒但拿走了你的健康」同一個等級，要先寫稿、先練過。

### ⚠️ 兩個一定要避開的講法

**不要講成「別的宗教都是假的」「你家拜的那些都沒用」。**
在場只要有一個人的媽媽初一十五在拜，這一句會把整關毀掉 —— 而且他不會再來。

**不要把它講成一道門檻**（「你不信就進不去」）。
那會讓今天第一次來的人覺得自己被關在外面，而這一關的功能是**遇見**，不是篩選。

### 安全的講法（三句）

1. **他說的是「到父那裡去」，不是「上天堂」。** 那是一個**家**，不是一個獎品。
2. 要進一個家的門，本來就只有一種方式 —— **那家的人帶你進去。**
   這句話不是在關門，是在說**有一個人願意帶你進去**。
3. **看他是講給誰聽的。** 上一節是多馬說「主啊，我們不知道你往哪裡去，怎麼知道那條路呢？」（約 14:5）——
   一個跟了他三年、還是聽不懂的**自己人**。**這句話是講給還在問路的人聽的，不是講給敵人聽的。**

> 第三句最重要。它把整節經文從「排他宣告」變回**一個帶路的人在回答一個迷路的朋友**。
> 而那正好就是他們剛剛走了三十分鐘的那張地圖。

## 十、流程表

十七頁，約 35 分鐘。**時間欄是「大約多久」，主畫面上不會有計時器。**

### 1 · 掃碼進場

### 2 · 接關（約 2 分）

跟第二關一模一樣的一頁：兩格數字，照卡片上抄。

| 問法 | 填什麼 |
|---|---|
| 「打開上一次的卡片，把**幸福指數**打進去。」 | 0–100 |
| 「底下那個**幸福根基**也打進去。」 | 0–95 |

> **忘記帶卡片：** 一顆按鈕改填「這是你第幾次來」，系統用 `15 ×（次數−1）` 估。
> **今天第一次來：** 幸福指數按現在的感覺填，**幸福根基自動給 15**（不是 0）。

> **大螢幕上不數第一次來的人，也不解釋他們拿到幾分。** 印在牆上就等於當著全場點名。
> 那個數字在主持人備忘錄裡。

### 3 · 人生模擬器 · 選一條路（約 8 分）

**互動點 1 · 主遊戲 · 這一關唯一會動幸福指數的地方**

一頁跑完五個岔路。左右兩大格，誰選了哪一邊馬上出現在格子裡。
底下那顆按鈕按到底：**公布結果 → 往前走 → 公布結果……** 岔路和結果見第一節。

> 「今天我們來模擬一次人生。二十歲開始，五個選擇，走到六十歲。」
> 「選你自己會選的那一個 —— 不用想哪個是對的。」

> **兩邊的名字加起來等於在場人數，才按「公布結果」。**

> **不要事先講「這裡面有陷阱」**，也不要在中途幫他們歸納規律。

### 4 · 三十二種人生（約 4 分）

**結算頁 · 三十二條全部攤開**

兩欄十六列，有人走到的排在左上角掛著名字，沒有人走到的淡淡地排在後面。
**這一頁要停久一點。**

主持人要講的那兩句在第一節最後（「選擇很重要／三十二條路你一條都看不到」）。

> **先問再講：** 「有沒有人覺得自己每一步都選得很穩，結果分數是負的？」
> 通常會有人舉手 —— 那句話由他講出來比你講有力十倍。

### 5 · 為什麼我們做不出最好的選擇？（約 1.5 分）

**信息 · 一句問句 ＋ 一句註腳**

底下那一句（「就算是 AI 也只是推測」）照著念，念完**停三秒**再翻頁。
**這一頁不要自己講出答案**，答案在下一頁。

### 6 · 因為罪（約 3.5 分）

**信息 · 七宗罪貼成標籤 · 罪就是射不中**

**第一句話先把「罪」和法律切開。** 內容和避雷見第二節。**這一頁不加分也不扣分。**

### 7 · 萬世巨星（約 2 分）

**介紹今天的主題**

內容見第三節。畫面左邊是聚光燈下的他，右邊是他說過的四句，底下是他留在生活裡的四樣。

### 8 · 這句話是誰說的（約 5 分）

**互動點 2 · 八題三選一 · 不加分**

題目和提醒見第四節。底下那顆按鈕按到底：揭曉答案 → 下一題 → 揭曉答案……

> 「剛剛介紹的那一位，他說過的話其實你早就聽過。我們來玩一個。」

### 9 · 八題的答案（約 1.5 分）

**解答頁**

八題排開，他說的那四句是亮的，其他四句淡下去。

> 「今天笑最大聲的那幾句，是周星馳、阿甘。最兇的那一句，是黃仁勳。」
> 「今天最兇的那一句，不是他說的。最溫柔的四句，是 —— **就是剛剛那一位。**」

### 10 · 就是這一位（約 2 分）

**揭曉 · 他站進第 7 頁那道空的光裡**

同一個構圖、同一個位置，只多了他。右邊是他說過的四句，底下是他留在生活裡的四樣。
內容見第三節。

> **「其實，你早就已經認識他了」是你要講出來的**，不印在大螢幕上。

### 11 · 你相信死後的世界有天堂和地獄嗎（約 2 分）

**互動點 3 · 投票 · 不加分**

內容和避雷見第五節。

### 12 · 永生的生命（約 2 分）

**信息 · 接第二關**

內容見第六節。

### 13 · 領受經文（約 2 分）

**經文 · 幸福根基 +10 · 七關共用的一頁**

領受完整的約 14:6，發第三張經文卡進卡包。大螢幕上只有經文，一句解釋都沒有。

### 14 · 藉著他到父那裡去（約 3 分）

**高潮 · 三段一次全出來 · 不加分**

內容見第八節，「若不藉著我」的講法見第九節。

### 15 · 祝福禱告 · 現在我覺得他是＿＿（約 2.5 分）

**互動點 4 · 開放輸入 · 幸福根基 +5 · 七關共用的一頁**

這一關的祝福禱告**有指定題目**。手機上**兩格，一頁做完**：

```
在今天以前，我認識的耶穌是……        ← 複選，點一點就好
  □ 一個歷史人物        □ 一個外國人的神
  □ 一個很會教人的老師   □ 一種宗教
  □ 我家裡有人信的那一位
  □ 我聽過，但真的沒想過他是誰

現在我覺得他是 ▁▁▁▁▁▁              ← 自己寫一句
```

**兩格都只有本人看得到，一個字都不會離開他的手機**，會並排印在卡片上。
**送出就幸福根基 +5**，全部寫完再帶禱告。

> **「以前」那一格要跟「現在」放在同一頁。** 兩行寫在同一個畫面上，他自己就會看到落差 ——
> **那個落差就是這一關。**

> **「現在我覺得他是」的開頭要印出來。** 空白的輸入框大家會寫「謝謝主」；
> 印了開頭，他才會真的去想那個空格填什麼。**這一句是這一關真正的產出**，第八週的護照就是靠它。

> **不要唸出任何一個人寫的東西**，即使他自己說可以。今天不是分享會。

### 16 · 儲存模擬回憶（約 1 分 · 七關共用的一頁）

生成第三張卡，當場長按存進相簿。**這一步一定要當場做完。**

### 17 · 下週預告（約 1 分 · 七關共用的一頁）

大螢幕上是今晚兩條線的全場平均，底下印著進來時的數字和差多少。
**這一關兩條線都是往上的。**

> 「他說『到父那裡去』。那條線怎麼接上——下一關。」

## 十一、要壓時間的話

約 33 分鐘，超過架構寫的 20–25。這一週是福音信息，值得超。真的要砍，順序是
（**先砍互動，不砍你的信息** —— 架構第二節）：

| 砍什麼 | 省多少 | 代價 |
|---|---|---|
| 猜句子從八題減到六題（拿掉第 2、4 題） | −1′ | **耶穌那四題（3、5、7、8）一題都不能拿掉**，第 1 題的笑也要留 |
| 地圖從五個岔路砍成三個（變八個結局） | −3′ | 正負打亂的力道會弱一半 —— **這是最後才砍的** |
| 第 11 頁的天堂地獄投票改成你直接問一句 | −1.5′ | 比例的畫面沒了，但那一頁本來就短 |

## 十二、這一關不決志

簡報最後一頁是決志禱告文。**第三關不用它。**

| | |
|---|---|
| **為什麼** | 今天是他第一次真的認識這個人。**認識和決定之間需要時間**，逼在同一個晚上會讓人退回去。 |
| **那福音講不完整嗎** | 講完整了 —— 罪、隔絕、代贖、到父那裡去、永恆的生命，第 5 到 13 頁全都在。**少的只有那個要求。** |
| **決志放哪裡** | 第六關「十字架的勝利」。那時候他已經看了六週，決定是他自己走到的。 |
| **今天的收尾句** | **「今天你不用做任何決定。」** |

**第 14 頁和第 15 頁手機上都沒有任何回應按鈕。** 唯一要按的是那兩格「以前／現在」，
而它們**只有他自己看得到**。

> 這跟第二關「拆完不要接決志」是同一條規矩。**任何形式的施壓都會毀掉這個時刻。**

## 十三、週卡

```
第三關 · 萬世巨星

幸福指數    36   (上週 27)
幸福根基    45

MY PATH
　打工 › 接下 › 投資 › 重來 › 每月

我認識的耶穌是
　一個歷史人物、我家裡有人信的那一位

現在我覺得他是
　「一個願意替我站上去的人。」

約翰福音 14:6
耶穌說：我就是道路、真理、生命；
若不藉著我，沒有人能到父那裡去。

2026.09.26　幸福小組
```

第三關的卡片和第二關的差別：**中間多了一組前後對照**，兩行都是他第 15 頁在同一個畫面上填的。
**這兩行是這一關真正的產出。**

另外卡片上多一行 `MY PATH`，印他在人生模擬器按的那五下 ——
隔週再看到這張卡，他想得起自己選了什麼。

> ### ⚠️ 幸福根基 +5 要他自己按下那顆按鈕
>
> 勾選會一路存上來（免得他勾完手機掉線就沒了），**但勾一個就給 +5、就跳「已存下」，
> 他會以為做完了**。所以 +5 和「已存下」都等他按下「寫好了」。
> 主持人手機上的「已填寫」數的也是按過按鈕的人 —— **你等的就是那顆按鈕。**

> ### ⚠️ 不給「下載」，給「開新分頁」
>
> 手機上那顆是**「放大這張卡」**，按下去**開一個新分頁，裡面只有那張圖**，
> 截出來就是乾淨的一張卡。
>
> 不要蓋一層 popup：popup 上的「關閉」和說明文字會一起被截進去。
> 也不要下載：檔案掉進資料夾裡就找不到了，而且 iOS 每支手機的下載流程長得都不一樣，
> 現場一定會卡住。**大家本來就都用截圖。**
>
> 做法是 `<a target="_blank" href="blob:…">` —— 真人點的連結不會被擋，
> 而且 **blob: 不是 data:**（Chrome 擋掉 data: 的頂層導航）。
>
> **第一關和第二關也改成同一套了**，七關的收尾動作一模一樣。

|---|---|
| **幸福指數整晚只有地圖會動** | 猜句子、罪、投票都不加分。分數散開，「你算不到結果」就不成立了。 |
| **五個岔路的正負不准有規律** | 讀書贏、拚贏、買房贏、換跑道贏、回家贏 —— 沒有一條規則貫穿五題。**也不准由你講出任何一條規律。** |
| **這一關會有人掉分** | 最多掉 19。掉的不要安慰、加的不要恭喜，一恭喜就變成比賽。 |
| **兩邊名字加起來等於在場人數才公布** | 公布之後那一個岔路就鎖住了，改不了。 |
| **結局頁三十二條全開** | 只看自己那一條是運氣，三十二條一起看才是「沒有規則」。**但不要念完三十二句。** |
| **不要事先講地圖有陷阱** | 讓他們用自己以為對的方式選完。 |
| **地圖那一段不要講成「不要努力」** | 重點是「你算不到」，不是「你不用算」。 |
| **第 5 頁念完要停三秒** | 那三秒的安靜就是這一頁。**不要自己講出答案**，答案在第 6 頁。 |
| **第 6 頁第一句先切開法律** | 「這裡講的罪，不是法律上的罪。」不拆掉這個聯想，後面「他替我們付了代價」全場都會覺得跟自己無關。 |
| **七個標籤不准變成點名** | 不問「你是哪一個」、不請人舉手。先講自己：「這七個我全都有過。」 |
| **「射不中」不印在牆上** | 第 6 頁畫面上只有那七個標籤，那一段是你講的。 |
| **罪那一段不指認任何人** | 是「我們都射不中」，不是「你射不中」。**你要把自己放進去。** |
| **罪那一頁一分都不動** | 加分變成「答對得分」，扣分變成「你承認越多扣越多」，兩種都會變成審判台。 |
| **天堂地獄那一題不糾正、不追問** | 沒有標準答案。比例出來就是接話點。 |
| **猜句子不要猜人名** | 選項是周星馳、黃仁勳、阿甘、孔子。**曼德拉那種沒有人會猜。** |
| **耶穌只佔四題（3、5、7、8）** | 前六題只有兩題是耶穌，才不會被無腦全選。 |
| **最兇的那句是黃仁勳說的** | 「今天最兇的那一句，不是他說的。最溫柔的四句，是。」**這是整個猜句子的重點。** |
| **引用活人的話不准改寫** | 第 4 題有明確出處。現場一定有人會查手機。 |
| **第 7 題要指出來** | 「這一句是我們第一關領的那張卡。」 |
| **第 8 題就是今天的經文** | 刻意讓全場都答對，**但猜完一個字都不要解釋**。它第 14 頁才會有意思。 |
| **萬世巨星那一頁不放你的台詞** | 「其實你早就已經認識他了」是你講出來的，不印在牆上。 |
| **第 14 頁一分都不加** | 那一段的重量靠你講，不靠數字。 |
| **不決志、不舉手、不點名** | 收尾句是「今天你不用做任何決定」。 |
| **祝福禱告的開頭要印出來** | 空白框大家會寫「謝謝主」。印了「現在我覺得他是」，他才會去想那個空格。 |
| **斷網備案** | 五個岔路請大家用站的分邊（左邊 A、右邊 B），每一次分完你就念出兩邊的結果和加減，走完五次自然分成好幾群。八題印成大字卡，念一題舉手表決一題。天堂地獄那一題舉手就好。數值用白板記。**站起來走過去比手機更有感。** |

### 版面的硬規則

**十七頁每一頁都必須在一個畫面裡看完，不准捲動。** 這一關最容易爆版的三頁：

- **第 3 頁**（四行 trail ＋ 公布後的左右兩大格）—— trail 只放人數和加減，不放名字。
- **第 4 頁**（三十二條 ＋ 名字）—— 兩欄十六列，行高和字級都封了頂。
- **第 5 頁**和**第 12 頁**（整頁一句話 / 回收上一關那一句）—— `white-space: nowrap` ＋ 字級跟著版面寬度縮，**不准斷行**。
