# 幸福模擬器 · 設計架構

幸福小組七關互動遊戲的骨架與共用系統。**開任何一關之前先讀這一份。**

投影片還在，只是活了過來。你照樣一頁一頁講，講到某個段落畫面會跳出問答或小遊戲，全場拿手機參與，玩完再回到你的信息。七關走完，每個人身上會長出一條自己的生命線。

| | |
|---|---|
| 依據 | 福氣教會幸福小組八週組題（第八週不設關卡） |
| 每關長度 | 20–25 分鐘（**幾天開一關由你決定，系統不假設每週一次**） |
| 裝置 | 主持人大螢幕（HDMI 接電視）＋ 玩家手機掃碼 |
| 對象 | 台灣三四十歲上班族為主的小組 |

**這是主持人的工具，不是自助遊戲。** 沒有人先準備好信息、沒有人在對的時機接話，它只是一堆會跑的動畫。

---

## 一、七週本來就是一個劇本

福氣教會的組題不需要硬套遊戲——它本身就是完整的英雄之旅：現況、覺醒、遇見、得力、反轉、決戰、結局。遊戲只要照著演，情緒自然會堆上去。

| 週次 | 主題 | 敘事功能 | 玩家在這一關第一次做到的事 |
|---|---|---|---|
| 01 | 真幸福 | 建立現況 | 說出自己以為的幸福長什麼樣 |
| 02 | 真相大白 | 覺醒 | 看見自己押錯了寶 |
| 03 | 萬世巨星 | 遇見關鍵角色 | 親手拼出「那個人是誰」 |
| 04 | 幸福連線 | 取得能力 | 第一次主動出手，而不是被事件砸 |
| 05 | 當上帝來敲門 | 視角反轉 | 回頭發現祂一直都在 |
| 06 | 十字架的勝利 | 決戰 | 和全場一起打贏一場仗 |
| 07 | 釋放與自由 | 結局 | 卸下背了七週的那顆石頭 |

第八週「幸福的教會」不設關卡，改為回顧與幸福護照發放。

## 二、運作模式：簡報骨架 ＋ 觸發式互動

這不是七套桌遊，是七套**會回應觀眾的投影片**。主導權在主持人手上：照原本的信息大綱一頁一頁走，走到設計好的轉折點時畫面切成互動頁，所有人的手機同時跳出東西給他們做，做完自動收合回信息。

| 頁型 | 大螢幕 | 玩家手機 | 主持人在做什麼 |
|---|---|---|---|
| 內容頁 | 就是投影片，你的信息 | 安靜，顯示自己的兩條指數 | 講 |
| 互動頁 | 即時匯集全場的答案 | 跳出問答或小遊戲 | 等、看、然後接著他們的答案講下去 |
| 分享頁 | 停在某個人的答案上 | 可按「我也是」「我為你禱告」 | 問一句：可以聊聊嗎 |
| 結算頁 | 本週指數變化、經文、小卡 | 收到自己的個人小卡 | 收尾、禱告 |

**一關放 3 到 5 個互動點，不要更多。** 互動太密會讓人一直低頭滑手機，反而聽不進你講的話。理想節奏是：講 5 分鐘 → 互動 2 分鐘 → 接著他們的答案再講 5 分鐘。互動的價值不在好玩，在於它給你一個真實的接話點。

### 主畫面不顯示累計時鐘

大螢幕上**不要有整場的計時器**。一個一直在跑的 `00:00` 會讓全場（和主持人自己）心急，而這套東西的節奏本來就該由主持人決定，不是由碼表決定。

例外只有一個：**拍賣或任何限時互動的倒數要留著**。那是遊戲機制的一部分，緊張感全靠它。差別在於——倒數是為了某一件事，時鐘是為了監視整場。

各關文件裡的時間欄一律當作「大約多久」，不是必須追上的進度。**超時的時候第一個該砍的是互動的量，不是你的見證。**

## 三、互動元件庫

每週內容不同，但能用的互動就這幾種。把它們當積木——每週只要決定信息大綱，然後在轉折處插進去哪一塊。這樣七週只要做一套系統，不用做七個遊戲。

| 元件 | 你得到什麼 | 說明 |
|---|---|---|
| 滑桿自評 | 一個數字 ＋ 全場分布 | 「你現在的幸福指數是幾分？」拉一下就好，零門檻。適合開場破冰、和信息前後對照。 |
| 選擇題 | 全場即時比例 | 大螢幕跳出比例的那一刻就是接話點：「有六成的人選了這個，為什麼？」 |
| 開放輸入 | 他們自己的原文 | 重擔、代禱、一句話。**預設不公開**，本人按下「我願意分享」才上牆。這些原文是七週資料最珍貴的部分。 |
| 隨機抽卡 | 自然發生的分享 | 同一頁每個人抽到的事件不一樣。抽完最自然的下一句就是「你抽到什麼？」——分享不用你逼出來。 |
| 情報交換 | 全場開口 | 每人手上一塊拼圖，誰都不完整，必須交換才拼得出來。內向的人也會因為手上有別人需要的東西而開口。 |
| 集體挑戰 | 同一條船的感覺 | 共用一條血條，不是個人排名。有人打不動別人補位。**合作制永遠優於競爭制。** |
| 互相指名 | 人和人真的連上 | 點某個人的名字為他禱告、送他分數、替他擋一次傷害。被點的人加分、點的人也加分。 |
| 領受經文 | 固定的收尾儀式 | 每週結尾發一張經文卡進玩家的卡包，同時長幸福根基。而且卡片在後面幾關真的有用。 |
| 翻自己的卡片 | 只有這個做法辦得到的東西 | 請大家打開相簿，翻出前幾週的卡，看自己當時寫了什麼。**不是系統播給他看，是他自己找出來的。** |
| 生成週卡 | 帶得走的東西 | 每關固定的收尾儀式。當場長按存進相簿——**不要說「回家再存」**，那張卡是下一關的入場券。 |

## 四、雙指數（整份設計最關鍵的機制）

如果幸福只有一條線、隨著好事壞事上下跳，那玩八週學到的會是「環境好我就幸福」——正好和幸福小組要傳的相反。所以拆成兩條。

### 幸福指數

| | |
|---|---|
| 名字 | **幸福指數**（七週都叫這個名字，不改） |
| 起點 | 第一關由玩家自評的 0–100 |
| 怎麼變動 | 被隨機事件推來推去：模擬生命中的事件、三十年折舊、主持人手動加減 |
| 上下限 | 0–100 |
| 重點 | **玩家控制不了它。這正是重點。** |

不要在名字裡加「外在」兩個字。加了就是在強調、在預告答案，而這個觀念要留到最後才給——**第八週回顧時才第一次說出「這條線其實只是外在」**，那時候他們已經看了七週的曲線，一句話就懂。

### 幸福根基

| | |
|---|---|
| 名字 | 第一關叫 **`???`**，第二關正式命名為 **幸福根基** |
| 起點 | 0 |
| 怎麼變動 | 只會漲，**沒有任何事件扣得到它** |
| 領受經文 | **+10**／關 |
| 收尾禱告 | **+5**／關 |
| 每關合計 | +15 |
| 上限 | **95**（不是 100） |

### 為什麼上限是 95

七關全勤是 `15 × 7 = 105`，撞到 95 的天花板。**那道牆是設計，不是 bug。**

| 出席次數 | 幸福根基 |
|---|---|
| 全勤 7 次 | 105 → **卡在 95** |
| 6 次 | 90 |
| 5 次 | 75 |
| 4 次 | 60 |
| 3 次 | 45 |
| 2 次 | 30 |
| 1 次 | 15 |

真的每一關都到的人不會太多，所以撞牆是少數人的體驗——但那少數人正是最需要看見這件事的人。第七關撞到的時候要有台詞，不然看起來像壞掉：

> 「你每一次都來了。它還是差 5 分。下次見。」

**你自己填不滿。** 這跟第二關「買三送一，那一份你一開始就拿到了」是同一件事的第二次出現，也是第八週的入口。整條線的邏輯是：靠領受和禱告能長到 95，最後那 5 分是白給的。

### 第一關就有兩條線

**第一關不是只有一條。** 兩條都畫出來，第二條的標籤是 `???`，而且**它有數字、它會動**。

第一關結尾的順序剛好是：模擬事件把幸福指數打下去 → 領受經文 `???` +10 → 禱告 `???` +5。他們會在自己掉分的同一個晚上，看見另一條線往上動了兩格，而且沒有人跟他們解釋那是什麼。

全場一定會有人問那是什麼。回答只有三個字：**下一關。**

第二關因此不是「解鎖一條新的線」，是**替一條早就在跑的線正名**。這比長出新東西強得多，因為驚訝已經在他們身上發生過一次了，第二關只是回收。

### 第八週補滿 100

第八週在信息**講到那個段落的中途**補滿——不是一報到就補、不是禱告完才補。所有人的幸福根基同時跳到 100。

> 「你們每一個人，今天都是 100。不是因為你來了幾次。」

只來過兩次的人跳 70 分，全勤的人跳 5 分——**兩個人在同一秒到達同一個地方**。這個畫面比任何一句話都有用。

**禮物要在補滿之後發，而且不能綁在分數上。** 只要第八週有來就有。分數換禮物會把整套訊息倒過來。

> ⚠️ **第八週可能在室外，不一定有電視。** 所以第八週的所有設計都必須在沒有大螢幕的情況下跑得完——補滿 100 那一刻可以只用口頭宣告加上他們手機上的畫面，不能依賴投影。

## 五、跨週怎麼接（沒有資料庫）

**不做帳號、不做跨週資料庫。** 一關一個獨立網頁，當晚即時同步，散會就結束。連續性靠玩家相簿裡的**週卡**。

> ### 遊戲本身不接前一關（第二關踩過這個坑）
>
> 接過來的只有那兩條線：**幸福指數**（他自己輸入）和**幸福根基**（從「第幾次來」推回來）。
> **那一關要玩的東西，一定要在那一關當場產生。**
>
> 第二關原本設計成「勾選你上一關標到的東西，然後驗貨」——結果是：上一次沒來的人得憑空編一份持有清單才玩得下去，而每一週都會有這種人。
> 改成「今晚當場在幸福人生商店挑三樣，然後坐時光機驗貨」之後，新朋友和老手走同一條路，而且**十分鐘前才做的決定，落差更痛**。
>
> 上一關的東西照樣可以講 —— 但它從主持人的嘴巴出來，不從系統出來。

第二關開始，開場的接關只做兩件事：

| 資料 | 怎麼接 | 為什麼 |
|---|---|---|
| **幸福指數** | 上一次有來的人**輸入**上一次卡片上的數字；第一次來、忘記帶卡、上一次沒來的人，直接按現在的感覺填一個 | 它是路徑相依的（拍賣、事件卡、手動加減），推不出來，只能輸入 |
| **幸福根基** | **不要叫他打字。問「這是你第幾次來？」點一下就好**，系統算 `15 × 次數`（上限 95） | 忘記帶卡片的人也答得出來，這條線自己會癒合 |

卡片上照樣印兩個數字給他看，但接關只要一個打字欄位加一個點選。第二關的接關只有 2 分鐘，兩個打字欄位會塞不下。

### 第三關以後第一次來的新朋友

**幸福根基直接給 15，不要掛 0。**

第五關才進來的人，旁邊一排是 30、45、60，他掛 0 會很難看。給 15 等於「你今天來了，今天就算一次」——而且這是真的，他今天確實會領受經文、確實會禱告。

側欄**不要按幸福根基排序**（維持進場順序）。介紹那條線的時候要包含這一句：

> 「這條線不是比賽。它從你來的第一天開始長。」

## 六、貫穿七週的四個系統

| 系統 | 生命週期 | 說明 |
|---|---|---|
| **雙指數** | W1 兩條都在（第二條叫 `???`）· W2 命名 · W7 並排揭曉 | 玩家全程看得到自己的兩條線，主畫面看得到全場的 |
| **週卡** | W1 → W7，共七張，存在他手機裡 | 每關結束生成一張直式圖卡：兩個數值、當週經文全文、他自己寫的那句話、日期。當場長按存進相簿。它同時是帶回家的經文、下一關接關的存檔、七週結束的紀念品。 |
| **重擔與鎖鏈** | W1 埋 · 每週 −2 · W7 卸下 | 第一關私下寫下的那句話，變成壓在角色身上的石頭，一路持續扣幸福指數。看得見、擺脫不掉、要別人幫忙才卸得下。 |
| **禱告牆與見證回顧** | W4 起收 · W5 開場必做 | 從第四關開始收代禱事項。不必每週回顧——集中用在第五關開場：「有沒有哪一條，這一次有回應了？」 |

## 七、人不固定，制度要吃得下

八週裡每週來的人都不一樣，這不是 bug，是幸福小組的現實。規則要為這件事設計，而不是遷就它。

- **新玩家 30 秒入場。** 當週關卡完全獨立可玩，前面的進度是「加成」不是「門檻」。
- **缺席不扣分。** 缺席只是那週沒加分，絕不倒扣。任何形式的懲罰缺席都會讓人更不想回來。
- **忘記帶卡片跟新朋友走同一條路。** 兩種都合法，不用解釋、不用道歉。
- **不必每週回顧。** 集中用在真正需要的兩個時刻：第五關翻卡片、第七關找出第一張卡。

> **誠實系統，不做防弊。** 有人會忘記存卡、有人會亂填數值、有人上一次沒來。都沒關係，這不是競賽。唯一要守住的原則是：**任何人、任何一關，都不會因為沒帶上一次的東西而玩不了。**

## 八、主持人主畫面

左側是每位玩家的名字、兩條指數、身上的重擔、經文卡數量。中間是本週場景。下方是一條**全場共用的能量條**。頂端**沒有計時器**。

> **不要做排行榜，要做團隊能量條。** 幸福小組不是競技場，排名會讓分數低的 BEST 覺得羞恥。反過來設計：**當某人指數全場最低時，觸發「全場為他禱告」事件，他大幅加分，團隊能量條跳一大格。**「耶穌來不是召義人」直接寫進遊戲規則裡。

控制列一定要有的：下一頁、跳頁、重跑當關的主遊戲、暫停（現場聊開了就該暫停）。

> **側欄不要放每個人的 ＋ −。** 試過，很怪：一排加減分鈕貼在名字旁邊，整個側欄看起來像在替每個人打分數，而這正是這套設計最想避免的東西。有人講了一句很棒的話，你就當場說出來 —— 那比 +5 有溫度。

### 大螢幕上只放給房間看的東西

**主持提示不要印在大螢幕上。** 「停久一點」「不要糾正他」「你要說的不是⋯⋯」這些是寫給主持人自己看的字，全場都看得到就很怪 —— 它會讓整個畫面讀起來像一份工作手冊，而不是他們正在玩的東西。

每一頁的內容分兩邊：

| 放哪裡 | 放什麼 |
|---|---|
| **大螢幕** | 題目、數字、分布、經文、卡片、每個人的兩條線。**副標（kicker）和標題留著** —— 它們是節目感的一部分。 |
| **主持人手機** | 要念的話、要做的動作、不要做的事、以及那一頁最該盯的即時數字。 |

判斷方法很簡單：**這句話如果被一個組員唸出來，會不會很奇怪？** 會的話就是備忘錄的內容。

### 主持人備忘錄（手機）

主持人自己的手機開一個網址，跟大螢幕連同一個房間，跟著大螢幕翻頁。

```
/hN                   → 第 N 關的備忘錄，讓他輸入四碼房號（/h2 就是第二關）
/hN?room=XXXX         → 直接連上那一間
```

**大螢幕右上角有一顆「📱 主持人備忘錄」按鈕**，點開跳出 QR，用自己的手機掃。按鍵盤 `N` 也可以，`Esc` 或點畫面任一處收起來。

掃不到就打 QR 底下那行網址（`/h1`、`/h2`），跟玩家一樣輸入四碼房號就連上了。**現場工具不能只有一條路。**


> 這個網址能翻頁。房號本來就是公開的，所以真正的風險是「有人亂翻頁」——惡作劇等級，不是安全問題。但還是別讓它整晚掛在牆上。

備忘錄上的東西：

- 現在在第幾頁、頁名、`3 / 16`
- **那一頁最該盯的即時數字**（幾人已作答、幾人已領受、全場平均掉到多少）
- **念**（金色）要講的話／**做**（綠色）要做的動作／**別**（橘色）不要做的事
- 底下一整排的**上一頁／下一頁**，拇指按得到 —— 主持人可以離開電腦走動
- **兩個方向都會同步**：大螢幕翻到哪，備忘錄自己跟到哪；從備忘錄翻頁，大螢幕也跟著走

內容放在各關的 `public/happiness/wN/notes.js`，渲染器 `shared/notes-page.js` 七關共用。**開新一關就是多寫一份 `notes.js`。**

大螢幕會用 HDMI 接 43–75 吋電視、觀看距離 2–4 公尺，所以主畫面的字級要隨畫面寬度整體放大（`--u` 縮放係數）。手機頁的字級固定放大一級——小組現場光線不一定好，年齡層也偏高。

## 九、第八週．幸福護照

不設關卡，改成回顧。做法是**請他們把七張卡片排出來**——手機相簿裡那七張，就是他這兩個月的生命軌跡。

每一本護照裡有：

- 第一週自評的那個數字，和第七週的兩條完整曲線並排
- 領受過的七段經文（同時做成實體卡片一起送）
- 第三關寫的「我以前以為耶穌是＿＿／現在我覺得他是＿＿」原文
- 第四關起寫過的代禱事項，以及哪幾條標記了「有回應」
- 第一週寫下的那顆石頭，和第七週卸下它的時間戳記、以及是誰為他禱告的
- 第六關那一晚全場一起打贏的紀錄

**這一週可能在室外。** 護照要能純紙本完成，補滿 100 那一刻也要能純口頭宣告。

「外在」這個觀念也在這一週第一次說出來——七條曲線都在他們眼前了，一句話就夠。

## 十、技術路線

```
worker/
  index.js       路由：/api/new-room、/ws、/1–/7、/h1–/h7，其餘丟給靜態資源
  room.js        Durable Object：一個房號一個房間，七關共用同一個 class
  wN-game.js     第 N 關的規則（純函式）
  wN-data.js     第 N 關的文案：卡組、標的、經文
public/happiness/
  zh-TW/         系列頁（主持人的準備台）
  shared/        七關共用：像素風元件、房間連線、週卡、QR
  wN/            第 N 關的主畫面、玩家手機頁、主持人備忘錄（notes.js）
```

七關共用同一個 Durable Object class，`/ws?week=N&room=XXXX` 決定連到哪一間。**加一關就是加 `worker/wN-data.js`、`worker/wN-game.js`、`public/happiness/wN/`，共用層不用動。**

玩家入場走 `/1`–`/7`，主持人備忘錄走 `/h1`–`/h7`，兩個都吃 `?room=XXXX`。網址越短 QR 模組越大、隔著電視越好掃，而且手機鍵盤打起來也不痛苦 —— 所以連查詢字串都不要。

`wrangler dev` 就是完整的伺服器（Worker + DO 都在本機跑），**現場斷網時可以直接用它跑完整場**，玩家連同一個 Wi-Fi、開你電腦的區網網址就好。

### 隱私三條線

- **重擔那句話不會離開玩家的手機。** 它存在他自己的 localStorage，伺服器只收到「有沒有寫」這個布林值。只有本人勾了「我願意分享」，那一句才會送上來。
- **房間狀態不做長期保存。** 寫進 DO storage 只是為了連線休眠後醒來還接得上；最後一個人離線六小時後整個刪掉。
- **週卡在瀏覽器端用 canvas 生成，圖不上傳。**

### 一定要有斷網備案

教會場地的 Wi-Fi 不能賭。每一關都要有一份紙本流程和事件卡，網路掛掉時可以無縫改用人工模式跑完整場。**紙本版通常不會比較差，有時候更有儀式感。**

## 十一、現場風險清單

| 風險 | 對策 |
|---|---|
| 遊戲蓋過關係 | 每關壓在 20–25 分鐘內，後面留足夠時間給分享、吃飯、禱告。**遊戲是引子，不是主體。** |
| 隱私外洩 | 重擔、捆綁、代禱這類輸入，預設只有本人看得到。必須本人按下「我願意公開分享」才上大螢幕，**沒有例外**。 |
| 低分被當成失敗 | 視覺上不要用紅色警示、不要用「危險」「不及格」這類字眼。分數低的人是被祝福的對象。 |
| 第一週亂填 100 分 | 那是防衛，不要糾正他。第二關他自己會發現那 100 分怎麼縮水的。 |
| 第二關把人打到低點 | 唯一一關會這樣，結尾一定要有出口。這一關的收尾稿要特別寫、特別練。 |
| 新朋友的第二條線落後 | 第三關起第一次來的人直接給 15，並且口頭說明「這條線不是比賽」。 |
| 大螢幕的計時器讓人心急 | 頂端不放計時器。只有限時互動本身有倒數。 |

## 十二、開新一關的檢查表

第三到第七關都照這個表走。**每一關的文件要回答完這幾題才算可以動工。**

### 內容

- [ ] 這一關的**敘事功能**是什麼（見第一節的表）
- [ ] 主持人這一週要分享的**信息大綱**——這是主體，其他都繞著它排
- [ ] **本週經文**，以及它在流程裡出現幾次、在哪裡出現
- [ ] **核心玩法**：這一關最主要的那一個互動點
- [ ] 3–5 個互動點各用哪一種元件、插在信息大綱的哪幾個轉折處
- [ ] 事件卡／選擇題文案（要貼近你們 BEST 的真實處境）

### 機制

- [ ] 幸福指數這一關**怎麼變動**（事件、選擇、主持人手動）
- [ ] 幸福根基這一關的 **+10 領受經文** 和 **+5 收尾禱告** 分別放在哪一頁
- [ ] 接關要問哪些東西（幸福指數輸入 ＋「第幾次來」點選）
- [ ] 新朋友的替代路徑（不能比 60 秒長）
- [ ] 這一關**用到前幾關留下的什麼**（只能是那兩條線）、**留下什麼給後面幾關**
- [ ] 這一關的主遊戲**在沒有前一關資料的情況下跑得完嗎**（見第五節）

### 現場

- [ ] 收尾的語氣曲線（尤其是會把人打低的關卡）
- [ ] 每一頁大螢幕要給房間看什麼、主持人手機的備忘錄要寫什麼（`wN/notes.js`）
- [ ] 斷網時的紙本版本
- [ ] 隱私預設：這一關有沒有開放輸入？預設關閉了嗎？

### 不要違反的四條

1. **不做排行榜。** 個人數值可以顯示，排名不可以。
2. **不懲罰缺席、不懲罰忘記帶卡片。**
3. **任何開放輸入預設不公開。**
4. **幸福根基只能漲。** 不管劇情多需要，都不准扣它——那是它唯一的意義。
